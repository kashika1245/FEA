# Phase 4 accessibility

- Semantic landmarks: complementary sidebar nav, main.
- Visible focus rings on controls.
- Status badges include a screen-reader “Status:” prefix; color is not the only cue.
- Charts have `role="img"` and a text summary.
- Forms use associated labels.
- Tables remain horizontally scrollable on small viewports.
- `prefers-reduced-motion` disables skeleton animation.
